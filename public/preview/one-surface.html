One Surface, with Crux's keyboard

Direction B for the daily gameplay page. It is a real board: eight words, four categories, two apiece. Type a word into the highlighted slot and press ENTER to guess it.

  • The keyboard is carried over unchanged. Same three rows, same 44px keys, same 6px radius, and the same three letter states from kbColors: A right letter, right place; B in the word, wrong place; C not in it. State is per word, so it resets as you move between slots.
  • The keyboard is a readout, not just an input. That is the argument for showing it on desktop by default rather than behind Show keyboard: physical typing makes the keys redundant as an input, but the colours are the only place that word's history is visible. The toggle is still here, it just starts open.
  • Check is gone from the control bar. ENTER submits the guess, so a second commit button was two ways to do one thing. The bar is now word navigation and the hint.
  • One ground, no card. The navy masthead and the saturated slab are gone and the board sits on the page. That is about 140px of chrome recovered on a phone, which is roughly what the keyboard needs.
  • The hue reaches the board as the 4px rule, the focus ring, the progress hairline and the avatar, while the keyboard keeps its own ink / amber / grey so game state never competes with brand colour. ENTER stays #233a63, the accent it already uses.
